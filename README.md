# ArtResource 제작 로그 · Art Resource Log

모스랜드(Mossland) 프로젝트에서 제작된 아트 리소스를 정리하고 공개하는 저장소입니다. 모스랜드 서비스에 사용되었거나 연구 목적으로 만들어진 각종 아트 리소스를 한곳에 모아, 새로운 모스랜드 프로젝트에서 쉽게 재활용할 수 있도록 하는 것을 목적으로 합니다.

This repository organizes and discloses the art resources created across Mossland projects. Its goal is to collect the various art resources used in Mossland services or produced for research so that they can be easily reused in future Mossland projects.

## 프로젝트 / Projects

| 프로젝트 | 내용 | 작업 시점 |
| --- | --- | --- |
| [Mossland Agora](Mossland_Agora/Mossland_Agora.md) | 오픈소스 거버넌스 플랫폼 '아고라'의 UI/UX 화면 플로우 | 2024 ~ |
| [Mossland Blog](Blog/Medium_Resource.md) | Medium 블로그 게시글용 아트 애셋 · 썸네일 | 2023.08 ~ 2024.03 |
| [Mossland Swap](Mossland_Swap/Mossland_Swap.md) | WMOC 스왑 사이트 디자인 (Figma) — 검수 완료 | 2023.07 ~ 2023.08 |
| [Mossverse](Mossverse/Mossverse.md) | 메타버스 맵 · 미니게임 · 인게임 UI 그래픽 | 2022.07 ~ 2023.07 |
| [Brick'd](Brick'd/Brick'd.md) | Zendog UI 레이아웃 (Figma) — 개발 잠정 보류 | 2022.07 |

대부분의 문서는 제작 시점 순으로 작업 내용과 결과 이미지를 기록하며, 아고라 문서는 화면 플로우(Home · SignIn · Proposal · Forum · Profile) 순으로 구성됩니다.

Most documents log their work and result images in chronological order; the Agora doc is organized by screen flow instead.

## 재활용 안내 / How to Reuse

- 각 프로젝트 폴더에는 정리 문서(`*.md`)와 원본 이미지 파일이 함께 담겨 있습니다.
- 문서 본문 이미지는 대부분 GitHub에 업로드된 링크로 삽입되어 있어, 링크를 그대로 참조하거나 필요한 리소스를 폴더에서 내려받아 사용할 수 있습니다.
- 리소스 사용 시 출처(모스랜드)를 표기해 주세요.
